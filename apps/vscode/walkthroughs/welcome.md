# Welcome to dTyp

**dTyp** is an offline academic C library and stealth typing assistant with **500 curated production components** across 7 computer science domains.

### What Makes dTyp Special?
- **100% Offline**: Embedded SQLite database runs entirely local using WebAssembly.
- **Zero-Comments Invariant**: Bloat-free, production C code verified with zero comments.
- **Parametric Variations**: Separate components and full programs with realistic data structures.
- **Activity Bar Integration**: Browse the entire library hierarchy directly from the dedicated sidebar.
