# Welcome to dTyp

**dTyp** is an offline academic C library and stealth typing assistant with **24,478 curated components** across 12 domains.

### What Makes dTyp Special?
- **100% Offline**: Embedded SQLite database runs entirely local using WebAssembly.
- **Parametric Variations**: Compilable implementations with iterative vs recursive variants, head vs double pointer semantics, and in-place vs allocated returns.
- **Activity Bar Integration**: Browse the entire library hierarchy directly from the new sidebar.
